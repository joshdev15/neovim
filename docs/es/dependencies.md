# Dependencias y Plugins

Esta configuración utiliza [Lazy.nvim](https://github.com/folke/lazy.nvim) como su gestor de plugins.

A continuación se muestra una lista de los principales plugins y dependencias utilizados en este proyecto:

| Categoría | Plugin | Descripción |
| :--- | :--- | :--- |
| **Gestor de Plugins** | [Lazy.nvim](https://github.com/folke/lazy.nvim) | Un gestor de plugins moderno para Neovim. |
| **UI y Apariencia** | [Catppuccin](https://github.com/catppuccin/nvim) | Un tema de tonos pastel relajantes para Neovim. |
| | [Gruvbox-Material](https://github.com/sainnhe/gruvbox-material) | Una versión modificada de Gruvbox con contrastes más suaves. |
| | [Lualine](https://github.com/nvim-lualine/lualine.nvim) | Una barra de estado ultrarrápida y fácil de configurar, escrita en Lua. |
| | [Tabby](https://github.com/nanozuki/tabby.nvim) | Un plugin de barra de pestañas declarativo, configurable y personalizable. |
| **Navegación y Archivos** | [Nvim-Tree](https://github.com/nvim-tree/nvim-tree.lua) | Un explorador de archivos en forma de árbol escrito en Lua. |
| | [Telescope](https://github.com/nvim-telescope/telescope.nvim) | Un buscador difuso altamente extensible sobre listas. |
| | [nvim-web-devicons](https://github.com/nvim-tree/nvim-web-devicons) | Proporciona iconos para varios plugins (requiere una Nerd Font). |
| **Integración con Git** | [Gitsigns](https://github.com/lewis6991/gitsigns.nvim) | Decoraciones de Git súper rápidas implementadas en Lua. |
| **Herramientas de Edición** | [Vim-Surround](https://github.com/tpope/vim-surround) | Facilita el uso de comillas y paréntesis. |
| | [Comment.nvim](https://github.com/numToStr/Comment.nvim) | Un plugin de comentarios inteligente y potente. |
| **LSP y Autocompletado** | [Mason](https://github.com/williamboman/mason.nvim) | Gestor de paquetes para servidores LSP, DAP, linters y formateadores. |
| | [Mason-LspConfig](https://github.com/williamboman/mason-lspconfig.nvim) | Crea un puente entre Mason y lspconfig. |
| | [Nvim-LspConfig](https://github.com/neovim/nvim-lspconfig) | Configuraciones de inicio rápido para el LSP nativo. |
| | [Nvim-Cmp](https://github.com/hrsh7th/nvim-cmp) | Un plugin de autocompletado codificado en Lua. |
| | [Nvim-Treesitter](https://github.com/nvim-treesitter/nvim-treesitter) | Mejor resaltado de sintaxis y comprensión del código. |
| **Específicos de Lenguaje**| [Go.nvim](https://github.com/ray-x/go.nvim) | Plugin moderno para Go basado en treesitter, nvim-lsp y dap. |
| | [Vim-Prettier](https://github.com/prettier/vim-prettier) | Un envoltorio de Vim para Prettier con ajustes predeterminados. |
